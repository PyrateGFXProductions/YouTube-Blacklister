## What this is
A Manifest V3 browser extension, vanilla JS, no bundler. It pins YouTube's "New to You" feed
and filters it with a local, server-invisible blacklist. Optional AI features call a LOCAL
Ollama at http://127.0.0.1:11434.

## Verify before you say "done"
Run these and report the real output — never claim a fix without it:
- `npm test`        — runs every `tests/*-harness.js` plus `test_ai_guardian.js`. Must pass.
- `npm run test:live` — exercises the live Ollama AI path (needs local Ollama running).
- `npm run package`  — PowerShell packager; writes the .xpi/.jar/.zip release artifacts.
- There is no build/transpile step: the repo is loaded unpacked for manual testing.

## Rules
- Thumbnail controls MUST be hover-revealed and must NEVER cause an accidental blacklist.
- Stay vanilla JS. Do not introduce a framework, bundler, or npm runtime dependency without asking.
- AI features stay local (Ollama). Never send user data to a remote service.
- Keep the blacklist server-invisible (no network calls carry user blacklist data).
- Run `npm test` after edits; paste the summary, and say plainly what passed and what did not.
